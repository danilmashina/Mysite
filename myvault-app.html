О проекте

MyVault помогает хранить рабочие доступы отдельно для каждого проекта: логины и пароли, API-ключи, Bash-команды и заметки. Нужную запись можно быстро найти поиском или фильтром по типу.

Проектам можно назначать оформление и значки. Записи редактируются, пароли генерируются, скрываются при просмотре и копируются. Напоминания содержат дату, время и список задач. Доступны светлая и тёмная темы, русский и английский интерфейс.

Что умеет MyVault:

  • 🗂️ Проекты и записи: отдельное пространство для доступов каждого проекта.
  • 🔎 Поиск и фильтры: быстрый доступ к паролям, ключам, командам и заметкам.
  • 🔑 Работа с паролями: генерация, скрытый просмотр и копирование.
  • 📅 Напоминания: дата, время и задачи, требующие внимания.
  • 📊 Экспорт: файл, который можно открыть в Excel.

Доступ и защита данных

Для входа используется Supabase Auth. Хранилище дополнительно открывается мастер-паролем: содержимое шифруется в браузере с помощью AES-256-GCM, а ключ выводится из мастер-пароля через PBKDF2-SHA-256. Правила доступа в Supabase ограничивают чтение и изменение записей владельцем. Есть автоблокировка и быстрый вход через WebAuthn на поддерживаемых устройствах.

PRO увеличивает лимиты. Оплата через ЮMoney обрабатывается серверным уведомлением с проверкой подписи.

Важно: экспортированный файл содержит данные в открытом виде — храните его осторожно. Если мастер-пароль забыт, восстановить зашифрованное хранилище нельзя.
